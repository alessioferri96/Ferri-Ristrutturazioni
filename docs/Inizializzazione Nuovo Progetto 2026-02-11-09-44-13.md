# Inizializzazione Nuovo Progetto Portfolio 2026-02-11-09-44-13

Questo documento descrive la fase iniziale dello sviluppo da zero del nuovo sito web per "Ferri Ristrutturazioni".

## Obiettivo
Creare un sito web moderno, leggero e performante che funga da portfolio per un'impresa edile, ottimizzato per il 2026 e facilmente integrabile come tema WordPress.

## Requisiti Tecnici
- **Stack:** HTML5, CSS3 (Moderno), JavaScript (Vanilla ES2026).
- **Architettura:** Struttura a file statici per massima velocità.
- **Design:** Moderno, con uso di CSS Grid/Flexbox, variabili CSS, e micro-interazioni fluide.
- **WP Ready:** Struttura dei file organizzata per facilitare la conversione in PHP per WordPress.

## Fasi di Sviluppo Proposte
1. **Fase 1: Setup Struttura**
   - Creazione di `index.html`.
   - Creazione della cartella `assets/css` con `style.css` (Design System).
   - Creazione della cartella `assets/js` con `main.js`.
   - Organizzazione delle cartelle per immagini e loghi.

2. **Fase 2: Design System**
   - Definizione di palette colori (Oro/Nero/Bianco per un look premium).
   - Tipografia fluida (Inter/Outfit).
   - Sistema di spaziatura coerente.

3. **Fase 3: Sviluppo Sezioni**
   - Header & Navigation.
   - Hero Section con impatto visivo.
   - Servizi e Portfolio.
   - Contatti e Footer.

## Verifica
- Test di reattività su diverse risoluzioni.
- Validazione semantica HTML.
- Controllo delle performance (Lighthouse).
